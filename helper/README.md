# KeySax Keys

Menu-bar listener, the same idea as Thock or Klack: it watches the keyboard and plays KeySax sounds itself. You do not need the KeySax window open for typing in other apps to make sound.

1. Unzip.
2. Double-click **Open.command** (or right-click **KeySaxKeys.app** → Open).
3. Allow **Device Control and Data Access** when asked (System Settings → Privacy & Security). If it is still silent, also allow **Input Monitoring**.
4. Leave the saxophone icon in the menu bar.

If macOS says the app can’t be opened, Open.command clears the download quarantine and starts it.
