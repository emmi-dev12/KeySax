# KeySax Keys

Menu-bar listener. It does not play sounds itself. It watches the keyboard and sends those keys into the KeySax you installed (Safari Add to Dock, or Chrome’s installed app), including while that window sits in the background.

1. Unzip.
2. Double-click **Open.command** (or right-click **KeySaxKeys.app** → Open).
3. Allow **Device Control and Data Access** when asked (System Settings → Privacy & Security).
4. Leave the saxophone icon in the menu bar, and leave KeySax open — it can stay behind other windows.

If macOS says the app can’t be opened, Open.command clears the download quarantine and starts it.
