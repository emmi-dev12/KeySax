# KeySax Keys

Menu-bar listener. Like Thock or Klack, it plays sounds itself while you type in other apps.

1. Unzip and open **KeySaxKeys** (double-click Open.command).
2. If macOS blocks it: right-click → Open.
3. Allow **Device Control and Data Access**. If it is still silent, also allow **Input Monitoring**.
4. Leave the saxophone in the menu bar.
