# KeySax Keys

Menu-bar listener. It does not play sounds itself — it sends keys into the KeySax app you installed.

1. Unzip and open **KeySaxKeys** (double-click Open.command).
2. If macOS blocks it: right-click → Open.
3. Allow **Device Control and Data Access** (System Settings → Privacy & Security).
4. Leave the saxophone in the menu bar, and leave KeySax open in the background.
